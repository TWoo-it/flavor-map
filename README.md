# Flavor Map: 지능형 주류 & 푸드 큐레이션 시스템

> **수학적 매칭 알고리즘(KNN 기반)과 오픈소스 LLM(Llama 3.1)이 결합된 초정밀 위스키 추천 대시보드입니다.**
> 개발을 전혀 모르는 분들도 단 1분 만에 내 컴퓨터에서 나만의 AI 소믈리에를 구동할 수 있습니다.

---

### [실시간 라이브 데모 체험하기](https://flavor-map-taewoo.streamlit.app)

## 주요 기능 (Key Features)
* **기존 위스키 기반 추천:** 내가 좋아하는 위스키를 고르면 맛 거리가 가장 가까운 대안 주류 매칭
* **내 입맛 맞춤 커스텀 추천:** 슬라이더를 조절하여 세상에 없는 내 취향의 위스키를 실시간 탐색
* **오늘의 안주 맞춤 추천:** 삼겹살, 방어회 등 오늘 먹을 안주의 풍미를 극대화할 최적의 페어링 역산
* **Llama 3.1 AI 페어링 가이드:** 100% 무료 오픈소스 LLM을 연동한 감성적인 스토리텔링 추천 사유 제공

---

## 1분 만에 실행하기 (Quick Start)

컴퓨터에 파이썬만 깔려 있다면, 아래 순서대로 복사해서 붙여넣기만 하면 앱이 켜집니다!

### 1. 소스코드 다운로드 및 폴더 이동
터미널(또는 명령 프롬프트)을 열고 아래 명령어를 입력하세요.
```bash
git clone https://github.com/TWoo-it/flavor-map.git
cd flavor-map
```
### 2. 필수 라이브러리 자동 설치
앱 구동에 필요한 패키지(Streamlit, Pandas, Plotly 등)를 한 번에 설치합니다.
```bash
pip install -r requirements.txt
```

### 3. 웹 대시보드 생성
아래 명령어를 입력하면 브라우저 창이 열리면서 예쁜 대시보드가 나타납니다!
```bash
streamlit run app.py
```

### AI 소믈리에 활성화 방법
1. Groq Cloud에 무료 가입합니다.
2. API Keys 메뉴에서 무료 API Key(gsk_...)를 발급받습니다.
3. 실행된 웹 화면 왼쪽 제어 패널에 키를 붙여넣으면 실시간 AI 가이드가 활성화됩니다! (비용은 평생 0원입니다.)
